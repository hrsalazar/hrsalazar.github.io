🚀 FASTEST WAY TO DEPLOY (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to https://github.com/new and create a new repo
   Name it: "portfolio" (or any name you like)

2. Push your code:
   git init
   git add .
   git commit -m "Portfolio with Timeline Modal"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main

3. Go to https://netlify.com
   • Sign up with GitHub
   • Click "Add new site" → "Import an existing project"
   • Select your portfolio repo from GitHub
   • Settings auto-fill (npm run build → dist)
   • Click "Deploy site"

4. Wait 1-2 minutes for deployment
   Your URL: https://your-site-12345.netlify.app

DONE! Your portfolio is live! 🎉
